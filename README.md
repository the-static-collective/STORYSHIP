# STORYSHIP

A provenance-first, append-only voyage runtime. The relationship is the passenger; artifacts are carriers; Haunted Phonography retains customs authority.

Launch v0 is dependency-free Node.js >=22 and remains no-spend until exact preflight gates and a human GO bound to an exact repository head and Transfer Packet 000 identity.

## Human-mediated crossing

```text
seal packet -> human carries declared input to provider
-> provider exposes observable sibling pair
-> human records observation
-> Storyship appends observation
-> human encounter + historical selector
-> candidate reaches HP customs
```

`storyship decide`, `storyship rank`, and `storyship admit` intentionally do not exist.
